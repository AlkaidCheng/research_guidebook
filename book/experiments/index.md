---
title: Experiments
summary: "Individual experiments as data sources: their accelerators, detectors, simulation and file formats, and what each dataset can and cannot be used for."
---

Each chapter in this part treats one experiment whose data the projects behind this book
use. It starts from the accelerator and the physics the experiment was built for,
describes the detector as it ran, follows an event through simulation and
reconstruction into the files that survive, and ends with the measurements that
validate those files and the references needed to use them.
